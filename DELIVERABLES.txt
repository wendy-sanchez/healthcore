INSTRUCCIONES DE USO

    Part3Pipeline,
    create_part3_pipeline,
    Part3PipelineState,
    DepartmentApprovalResponse,
)

EJECUTAR WORKFLOW:
──────────────────
part3 = create_part3_pipeline()

    ticket_id="rfp-001",
    part2_handoff={...},
    rfp_metadata={...},
)

─────────────────────
final_state = part3.handle_approval_response(
    ticket_id="rfp-001",
    department_id="revenue",

        "approver_email": "tom@healthcore.com",
    }
)
